# RJPQ Tool

This repo contains a browser-based MapleStory Romeo and Juliet Party Quest helper.

## Deploy

This project can be deployed as a static site with GitHub Pages.

1. Push the repository to GitHub.
2. Open `Settings` -> `Pages`.
3. Set `Source` to `Deploy from a branch`.
4. Select branch `main` and folder `/docs`.
5. Save and wait for Pages to publish.

The deploy entry is:

- `docs/index.html`

## Project Notes

- `public/index.html` is the active working file.
- `docs/index.html` is the GitHub Pages deployment copy.
- The project is currently maintained as a static single-page site.
